## Technique Categories for NLP Analysis

Scripts can be grouped by linguistic strategy for computational analysis:

1. **Authoritative/Direct** — Commands, imperatives ("Sleep now", "Close your eyes")
2. **Permissive/Indirect** — Suggestions, possibilities ("you might notice...", "perhaps...")
3. **Confusion/Overload** — Paradoxes, cognitive load, dissociation language
4. **Ideomotor** — Suggestions tied to involuntary body responses (arm lift, finger spread)
5. **Imagery/Metaphor** — Guided visualization, nature scenes, safe places
6. **Fractionation** — Repeated open/close cycles to deepen state
7. **Countdown/Counting** — Numerical deepening (20→1, elevator floors, etc.)
