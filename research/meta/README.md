# Research Library

Organized knowledge base. Each topic gets its own folder.

## Structure

```
research/
├── README.md          (this file)
├── _index.md          (searchable topic index)
└── [topic-name]/
    ├── README.md      (overview + key takeaways)
    ├── sources.md     (links, references, citations)
    ├── notes/         (detailed research notes)
    └── assets/        (PDFs, images, raw files)
```

## How It Works

**New research:** I create a topic folder, gather info, summarize findings.

**Revisiting:** I check the folder first before searching again — builds on existing knowledge.

**You adding stuff:** Drop files in a topic folder or create a new one. I'll incorporate it.

## Topic Naming

Lowercase, hyphens, descriptive:
- `ai-agents` not `AI Agents`
- `tax-strategies-2026` not `taxes`
- `competitor-analysis-acme` not `competitors`

## Index

See `_index.md` for all topics with one-line descriptions.
