# OpenClaw & Tech News Tips (March 28th, 2026)

## OpenClaw v2026.3.24 (Latest)
- **OpenAI/RAG Compatibility**: Added `/v1/models` and `/v1/embeddings` endpoints for broader tool support.
- **Enhanced Teams UX**: Official SDK migration with streaming 1:1 replies and native AI labeling.
- **Improved Control UI**: New status-filter tabs for skills, click-to-detail dialogs, and expandable workspace file rows with inline markdown preview.
- **One-Click Skill Setup**: Added install recipes for bundled skills (coding-agent, tmux, weather, etc.) to automate dependency installation.
- **Security**: Hardened skill installer metadata and tightened media-root access for sandboxed agents.
- **Runtime**: Lowered Node 22 floor to 22.14+ (recommending Node 24).
