### Supabase Foreign Table Filter Bugfix (2026-03-08 1:47 AM)
- **Bug**: State/Fleet filters crashed in UI when targeting the inner joined `companies` table (e.g. `.in('companies.phy_state', ['TN'])`). SupabaseJS v2 fails translating array/range syntax through foreign references.
- **Solution**: Swapped `.in()`, `.gte()`, `.lte()` to raw PostgREST `.filter()` strings (e.g. `.filter('companies.phy_state', 'in', \`(${selectedStates.join(',')})\`)`) in both `page.tsx` and `route.ts`. Pushed as commit `1a31009`.
